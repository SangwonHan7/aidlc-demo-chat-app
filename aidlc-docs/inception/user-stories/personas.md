# Personas - QuickChat

## Persona 1: 일반 사용자 (팀원)
- Description: 실시간으로 동료와 대화하는 조직 구성원
- Primary Need: 빠르고 안정적인 메시지 송수신, 대화 이력 확인
- Goals: 이메일보다 빠르게 소통, 필요한 채널/DM만 확인
- Pain Points: 여러 툴에 대화가 흩어져 있어 추적하기 어려움

## Persona 2: 채널 관리자
- Description: 팀/프로젝트 채널을 생성하고 구성원을 관리하는 사용자 (일반 사용자 권한을 포함하는 상위 역할)
- Primary Need: 채널 생성, 구성원 초대/관리, 채널 공개 범위 설정
- Goals: 프로젝트 단위로 빠르게 팀 채널을 구성하고, 적절한 사람만 참여시키기
- Pain Points: 채널이 공개로만 존재하면 무관한 사람이 들어올 수 있음 -> 초대 전용 옵션 필요 (FR-4)
